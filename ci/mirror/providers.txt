# Providers the schema mirror publishes. One provider per line: <namespace>/<name>, then
# optionally a minimum version written >=x.y.z, then optionally versions to skip, each
# written !x.y.z. Text after # is a comment.
#
# Each run publishes every stable version of each provider that is not published yet,
# newest first, up to the run's version cap; the rest wait for the next run. A minimum
# leaves out every version below it, for example:
#   hashicorp/random
#   hashicorp/google >=4.0.0
#   hashicorp/google >=4.0.0 !4.1.0 !4.2.3
# Versions built only for plugin protocol 4 (Terraform 0.11) are left out on their own:
# current terraform cannot read their schema.
# Skip a version only when its build fails on consecutive nights: a version that always
# fails would otherwise take a slot of every run.
# List only providers licensed under MPL-2.0: the release notes and NOTICE state that
# license.
